# PrestamoLaptopsUPN

Sistema en Java para gestionar el préstamo de laptops a estudiantes de la UPN.

## Descripción

Sistema de gestión de préstamos y devoluciones de laptops desarrollado en Java con Apache NetBeans.

## Tecnologías

- Java
- Apache NetBeans 32
- Programación Orientada a Objetos

## Estructura del proyecto

- `interfaz/`: pantalla principal (`FrmPrincipal`).
- `modelo/`: clases `Estudiante`, `Laptop` y `Prestamo`.
- `principal/`: clase `Main`.
- `servicio/`: lógica del sistema (`SistemaPrestamos`).

## Cómo ejecutarlo

1. Clona el repositorio.
2. Abre el proyecto en NetBeans.
3. Ejecuta la clase `Main.java`.
